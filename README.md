# 🔮 AI 사주 만세력 — 종합 역학 풀이

실제 절기·삭망 **천문 계산 기반 만세력 엔진**을 내장한 무료 정적 웹앱입니다.
API 키 없이, 빌드 과정 없이 동작하며 **랜덤 문장 생성이 없습니다** — 동일한 입력이면 항상 동일한 결과가 나옵니다.

## 주요 기능 (MVP v1)

- **만세력 계산**: 태양 황경 기반 24절기, 삭망(Meeus 천문 알고리즘), 음양력 변환(윤달 포함),
  한국 표준시 역사 변경(1908~1911, 1954~1961 UTC+8:30) 반영, 진태양시(경도) 보정
- **사주 원국**: 년·월·일·시주, 십신, 십이운성, 지장간, 공망, 납음오행, 띠
- **오행 분포** 차트와 과다/부족 풀이
- **성격·기질** (일간 10간 풀이), 강점·약점·재능·적성
- **신강·신약 / 용신·희신·기신** (억부 중심 간이 판단)
- **분야별 운**: 재물운·직업운·애정운·건강운
- **대운** 타임라인 (순행/역행, 대운수 계산)
- **운세**: 올해·이번 달·오늘 (세운·월운·일운의 십신 + 합충 기반 점수)
- **천기누설**: 향후 10년 기회·재물·귀인·주의 시기
- **행운 정보**: 용신 오행 기반 색·숫자·방향·음식·아이템, 재미용 번호(결정적 시드)
- 결과 **링크 공유** / **인쇄·PDF 저장**

## v3 추가 기능

- **🌅 오늘의 운세 위젯**: 한 번 풀이하면 프로필이 브라우저(localStorage)에 저장되어,
  재방문 시 첫 화면에서 재물·애정·건강·직업 별점 + 한줄조언 + 행운색·숫자를 바로 표시
- **📈 10년 운세 그래프**: 종합·재물·애정·건강·직업 탭별 연도 점수 막대그래프 (호버 툴팁, 고점·저점 해설)
- **💬 상담 고도화**: 카테고리 18종(대출·자동차·가족·유학·여행·소송·인간관계 추가),
  고위험 질문(대출·투자·창업·소송)은 겁재·재다신약·기신 세운·충 기반 **위험도 점검** 후 보수적 결론,
  세션 내 **질문 기억**("앞서 대출을 고민하셨지요…")
- **💞 궁합 인연 그래프**: 첫 만남·결혼·재물·갈등 회복력·노후 5국면 별점
- **📅 택일 기간 옵션**: 오늘 / 30일 / 3개월 / 1년 (장기 스캔은 ★4 이상만 표시, 절기 계산 캐시로 0.1초대)
- **📄 인쇄 리포트**: 표지(사주팔자·발행일) + 장(章) 단위 페이지 구분의 철학관 리포트 스타일 인쇄/PDF

## v2 추가 기능

- **💬 AI 사주 상담**: 질문(자유 입력 + 카테고리 버튼 10종)을 퇴사·창업·투자·부동산·연애·결혼·시험·취업·건강·금전으로
  분류한 뒤, 원국 구조 → 현재 대운 → 세운 → **향후 12개월 월운 스캔**을 근거로 상담사형 답변을 조립합니다.
  (LLM 아님 — 엔진 계산 기반 규칙 조립이라 결정적이며 API 키가 필요 없습니다)
- **💞 궁합**: 상대 사주 입력 → 일간(천간합/상생)·일지(육합/삼합/충/원진)·오행 보완·띠·용신 상호지원의
  5개 항목 100점 만점 분석 + 갈등 요소/개선법/결혼 적합도
- **📅 택일**: 앞으로 30일의 일진을 내 사주와 대조해 목적별(계약·이사·개업·면접·시험) 별점과 추천 길일 TOP 3
  (공망일·일지충 감점, 이사에는 음력 손 없는 날 가점)

## v4 (출시 전 품질)

- **🔍 판단 근거 공개**: 모든 상담 답변에 "왜 이렇게 판단했나요?" 펼치기 —
  원국/대운/세운/월운 각각의 별점·이유와 판단 체인(예: `대운 편재(기신) → 세운 정인 80점 → 보수적 판단`)
- **전문가 안내 문구**: 건강·소송·대출·투자·부동산 상담에는 의료/법률/재정 전문가 상담 권고를 자동 첨부
- **📈 연도 클릭**: 그래프 막대 클릭 → 해당 연도 세운 상세(십신·도메인별 별점·이유)
- **📄 표지 점수**: PDF 표지에 올해 종합 운세 점수 표시
- **📱 모바일**: 375px 기준 가로 스크롤 0px, 원국 표·그래프·세그먼트 최적화
- **정확성 검증 확대** (`test/accuracy.test.js`): 일진 60갑자 연속성 5.5만 일,
  음양력 왕복 4만 일, 설날 앵커 15개 연도, 윤달 9개 사례, 절기 5종 × 100년 범위,
  시주·일주 경계(정자시·진태양시), 대운수 범위 표본 88건

## 알려진 한계

- 절입 시각 경계(±수 분)에 걸친 출생은 오차 가능성이 있어 전문가 확인을 권장합니다.
- 용신 판단은 억부 중심의 간이 로직이며, 유파에 따라 결과가 다를 수 있습니다.
- 관상·손금(사진 분석), AI 자유 상담(LLM), 궁합·택일·작명은 로드맵 항목입니다.

## 로드맵

1. **PDF 리포트**: 철학관 리포트 스타일의 상세 출력 (현재는 브라우저 인쇄 기반)
2. **오늘의 운세 위젯**: 첫 화면에서 재물·애정·건강 별점 요약
3. **작명**: 획수·오행·발음 기반 이름 점수
4. **AI 자유 상담**: Claude API 연동 시 원국·대운·세운 데이터를 컨텍스트로 넘겨 자유 질의응답
5. **평생 리포트**: 출생~90세 대운·세운 그래프
6. GitHub Pages 배포 (정적이므로 push만 하면 됨)
